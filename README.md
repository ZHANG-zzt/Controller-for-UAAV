# Controller-for-UAAV
This paper proposes an Uncertainty-Aware Adaptive Nonlinear Model Predictive Control (NMPC) framework, termed UA-ANMPC, for underwater motion control of tilt-rotor Unmanned Aerial-Aquatic Vehicles (UAAVs), which face significant challenges from complex hydrodynamic interactions and time-varying disturbances.
# Building Requirement
* GPU: At least 8GB VRAM
* Install [ROS2 Humble](https://docs.ros.org/en/humble/)
* Ignition Gazebo simulator
* Ubuntu 20.04/22.04
* Python 3.9+
